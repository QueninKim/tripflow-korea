지역 간 이동 · 시간표와 무료 API

기차는 코레일의 2026.11.01 기준 KTX·일반열차 공개 시간표에서 1,077개 편, 256개 역 이름을 수록했습니다. 날짜별 운행요일과 자정 이후 도착을 적용합니다. 자료의 조건을 해석할 수 없는 일반열차 2건은 제외했습니다. 경기 판교와 충남 판교는 구분합니다.

  • 한국철도공사 공식 시간표 목록: KTX 시간표(2026.11.1. 기준), 일반열차 시간표(2026.11.1. 기준). 출발·도착 시각, 편명, 운행요일의 사실 자료를 검색용으로 연결했습니다. 공개 시간표는 잔여석·지연·임시 또는 명절 운행을 확인하는 서비스가 아닙니다. 예매 전 공식 조회에서 여행일의 실제 운행을 확인하세요.
  • 한국철도공사_철도운행거리_전체: 2024.09.01 기준 거리표. 이용허락범위 제한 없음. 출발·도착역이 동일한 공식 선구별 거리표 안에서 일치할 때 참고 거리를 표시합니다. 고속·일반선 또는 경유 경로가 섞여 명확히 대응하지 않는 경우에는 거리를 비워 둡니다. 실제 선택 편의 경유에 따라 거리 차이가 있을 수 있습니다. 자동차·직선거리로 대체하지 않습니다.
  • 한국철도공사_역 위치 정보: 2024.04.01 CSV, 이용허락범위 제한 없음. 일치하는 185개 역의 위치만 새 일정 장소로 추가할 수 있습니다. 위치가 불명확한 행신과 좌표가 없는 신설역은 새 장소로 임의 생성하지 않으며, 기존 일정 이동 구간에 승차편을 적용할 수 있습니다.

일정에 반영하는 방법

기차·지역 간 이동 → 출발역·도착역·날짜 선택 → 시간표 조회 → 승차편 선택 → 기존 이동 구간 또는 일정 끝에 추가를 선택합니다. 역까지 이동과 하차 후 이동은 직접 분 단위로 입력합니다. 전체 시간은 접근 + 출발 시각까지 대기 + 탑승 + 하차 후 이동입니다. 앞 일정으로 탑승 여유시간에 맞출 수 없는 편은 적용하지 않습니다. 같은 날짜의 일정에 적용하며, 다른 날짜·앞 일정 변경으로 탑승할 수 없으면 재확인 표시와 이동시간 미정으로 바뀝니다.

시외·고속버스·항공편은 예약한 편의 출발·도착 시각과 선택적인 이동거리를 직접 입력해 같은 방식으로 반영합니다. 현재 이 두 수단의 자동 시간표·자동 거리 조회는 연결되어 있지 않습니다.

무료 API 신청

  1. 공공데이터포털에서 회원가입·로그인합니다.
  2. 국토교통부_(TAGO)_열차정보의 ‘활용신청’을 선택합니다. 활용 목적은 ‘외국인 대상 국내 여행 일정에서 출발·도착역과 여행일별 열차 시간표 조회’로 적을 수 있습니다.
  3. 승인 후 마이페이지의 활용신청 현황에서 해당 API와 일반 인증키를 확인합니다. 인증키는 공개 웹파일이나 여행자 화면에 넣지 않고 서버에 보관합니다.

TAGO 열차정보는 무료이며 JSON/XML을 제공합니다. 열차 출발·도착 시각 조회 API이며, 좌석 예약이나 지연·도착 실시간 추적 API와는 다릅니다. 현재 배포본에는 인증키가 연결되지 않아 공개 시간표를 사용합니다. 서버가 연결되면 날짜별 TAGO 조회를 우선하고, 오류가 나면 출처를 명시한 공개 시간표로 전환합니다.

추가 수단은 별도로 고속버스정보, 시외버스정보, 국내항공운항정보를 신청할 수 있습니다. API별 제공 날짜·운행 범위가 다릅니다.

English

Train searches use 1,077 published Korail services effective 1 November 2026, applying each service’s operating weekdays. Published schedules are separate from seats, live delays and special services. Distances are matched official rail-corridor references dated September 2024; unavailable or ambiguous corridors remain blank. Enter access/egress minutes and choose a service to apply its scheduled departure and arrival to your itinerary. Changes that make boarding impossible require review. Buses and flights currently support manual booked-service entry; their automatic feeds are not connected.

Free official train API: MOLIT TAGO TrainInfo. A server-side service key is required. The published app currently uses the file timetable; no API key has been activated.
